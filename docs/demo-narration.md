## 录屏与旁白对应

只使用原创虚构字幕；录制应用页与需要展示的实际导出内容。隐藏通知、私人文件名、账号、系统路径和其他应用。实跑模型的名称与运行状态可在画面标注，未取得真实响应前不进入下一步。允许剪去等待，但须标明“等待已剪辑”，不得伪装实时延迟。

| 字幕段 | 时间 | 实际操作或画面 |
| --- | --- | --- |
| 1–2 | 00:00–00:16 | 项目标题，展示虚构字幕和交接问题；不放用户数量或成效数字 |
| 3–4 | 00:16–00:32 | 实际导入SRT/VTT，展开时间轴、阅读速率和术语检查依据 |
| 5–6 | 00:32–00:50 | 启动真实本地Ollama Agent，展示实际工具结果与模型文字建议 |
| 7–8 | 00:50–01:08 | 展开同一条的原文/建议，接受一条，保留另一条；使用当次真实内容 |
| 9–10 | 01:08–01:26 | 导出并实际查看字幕与审计JSON，指出剩余问题 |
| 11–12 | 01:26–01:50 | 当前限制、模型/程序分工、后续验证计划；结束于可试用或本地运行说明 |

这些字幕段内的操作需按真实耗时剪辑。不要为赶脚本跳过接受、下载或打开文件等关键动作。模型返回不同内容时，应相应修改第6至第8段，保留“只改文字、用户逐条决定”的事实。

下列SRT文本也是旁白逐段原文；不额外插入未配字幕的旁白。生成或录音后，必须按实际发声重新对齐这些时间码，逐段复听，避免字幕超前、缺段或被操作遮挡。
